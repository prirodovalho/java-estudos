# Java Estudos ☕

## Sobre o projeto

Este repositório reúne meus estudos práticos em Java, com foco no desenvolvimento Backend e na construção de uma base sólida para aplicações utilizando Java e Spring Boot.

O objetivo é consolidar conceitos da linguagem por meio de exercícios, exemplos práticos e pequenos projetos, evoluindo gradualmente para aplicações REST e arquiteturas de microsserviços.

## Tecnologias

- Java SE
- Eclipse IDE
- Git e GitHub
- Maven (etapa futura)
- Spring Boot (etapa futura)
